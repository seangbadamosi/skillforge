# Skillforge
 A learning and career platform built progressively during my frontend development internship

## Project Overview

SkillForge is a learning and career platform designed to help beginners and self-taught learners develop practical digital skills, build real-world projects, and prepare for career opportunities.

This multi-page website built with HTML and CSS as part of my frontend development internship. It focuses on semantic HTML structure, accessible form labels, and consistent navigation and responsive styling.

## Target Audience

SkillForge is designed for:

* Complete beginners learning digital skills.
* Self-taught learners who need direction and practice.
* Aspiring technology professionals.
* Learners looking to gain practical experience and discover career opportunities.

## Website Pages

* **Home:** Introduces SkillForge and explains its purpose.
* **About:** Presents the platform's mission, vision, and target audience.
* **Contact:** Provides a contact form with name, email, and message fields.

## CSS Concepts Learned 
* **Margin:** Creates space outside an element's border, separating it from other elements.

* **Border:** Creates a visible edge around an element.

* **Padding:** Creates space between an element's content and its border.

## Styling Features
* One shared CSS file linked to all three HTML pages.
* Element selectors, class selectors, and the :hover pseudo-class.
* A consistent colour palette and typography.
* Navigation hover effects and spacing using the CSS box model.
